Apple Magic Trackpad Setup Utility + Drivers v1.0
=================================================

This archive contains EVERYTHING needed on a fresh Windows host: the
Microsoft-signed driver package, the tray control panel and the PowerShell
utilities. One click installs all of it.

Attribution: the driver, the control panel and the haptic protocol come from
vitoplantamura/MagicTrackpad2ForWindows and imbushuo/mac-precision-touchpad
(and the contributors listed in README.txt); this package adds the tray
extensions, the installer and the maintenance tools.

--------------------------------------------------------------------------------
QUICK START (new host, 3 steps)
--------------------------------------------------------------------------------

1. Extract this folder anywhere, e.g. C:\MagicTrackpad
   (do not run it from inside the ZIP).

2. Double-click   Install.cmd
   Windows shows one UAC prompt - confirm it. Nothing else to type or click.

   Prefer a console? The same thing from any prompt:

       powershell -ExecutionPolicy Bypass -File .\install.ps1

3. The installer

       - trusts the driver certificate(s) from .\certs
       - imports the driver package from .\driver  (pnputil /add-driver /install)
       - re-scans the device tree and reports the trackpad state
       - copies the control panel to %LOCALAPPDATA%\MagicTrackpad
       - starts it (accept the second UAC prompt: the panel needs admin)

Useful switches:

       -Autostart            also register "start with Windows" (one UAC per logon)
       -StartMinimized       with -Autostart: start straight into the tray
       -DriverOnly           install only the driver + certificates
       -SkipLaunch           install everything but do not start the panel
       -InstallDir <path>    install the panel somewhere else
       -Uninstall            remove panel, autostart, driver package, certificates

--------------------------------------------------------------------------------
WHAT IS IN THE ARCHIVE
--------------------------------------------------------------------------------

  Install.cmd                  DOUBLE-CLICK THIS - asks for admin rights once and
                               runs install.ps1 (optional arguments are passed on)
  Uninstall.cmd                the reverse: panel, autostart, driver
  Uninstall-All-Apple-Drivers.cmd
                               clean slate: removes EVERY known Apple / Magic
                               Trackpad driver package and leftover device
                               instance (use this when the panel reports
                               "Failed to open device. Error: 2")
  Uninstall-All-Apple-Drivers.ps1   the same, with -DryRun to only list things
  Diagnose.cmd / Diagnose.ps1   writes MagicTrackpad-diagnose.txt (everything
                               about the panel, driver and devices) - run this
                               when something does not work and send the file
  install.ps1                  one-shot installer / uninstaller (the actual steps)
  AmtPtpControlPanel.exe       tray control panel (elevated, single instance)
  README.txt                   what the control panel does, option by option
  INSTALL.txt                  this file
  driver\AmtPtpDevice.inf      the driver package, SIGNED BY MICROSOFT (Windows
                               Hardware Compatibility Publisher). Needs no test
                               signing and no certificates - the default.
  driver\AmtPtpDevice.cat      catalog signed by MtPtpSigner / MtRootCA
  driver\AmtPtpDeviceUsbUm.dll user-mode WUDF driver
  driver\AmtPtpHidFilter.sys   kernel HID filter
  utility\MtTrackpad.ps1       setup / control utility (headless friendly)
  utility\Verify-MtTrackpad.ps1 unattended PASS/FAIL verification
  utility\Remove-MtCerts.ps1   removes the trusted test certificates again

The utilities work on their own as well and find the driver folder
automatically:

       .\utility\MtTrackpad.ps1 install
       .\utility\MtTrackpad.ps1 status
       .\utility\Verify-MtTrackpad.ps1

--------------------------------------------------------------------------------
REQUIREMENTS
--------------------------------------------------------------------------------

  * Windows 10 or 11, x64
  * Administrator rights (driver install + the control panel's elevated token)
  * The trackpad connected by USB-C (first-time setup) or paired over Bluetooth
  * Nothing else - no WDK, no Visual Studio, no .NET download (.NET 4.x ships
    with Windows)

--------------------------------------------------------------------------------
MANUAL INSTALL (if you prefer doing it by hand)
--------------------------------------------------------------------------------

    # 1. import the driver (admin) - it is Microsoft-signed, nothing to trust
    pnputil /add-driver driver\AmtPtpDevice.inf /install
    pnputil /scan-devices

    # 2. start the control panel (accept UAC)
    .\AmtPtpControlPanel.exe

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------

"pnputil ... failed / the driver package is not signed"
      The certificate was not trusted. Re-run install.ps1 (it imports into
      Root, CA and TrustedPublisher) and check with:
          certutil -store Root | findstr /i mt
          pnputil /enum-drivers | findstr /i amtptp

Device present but "not started" / nothing reacts to the trackpad
      Unplug and replug the USB-C cable, then re-run with -DriverOnly.
      Check Device Manager: "Human Interface Devices" should show the
      Magic Trackpad entries with no warning triangle.

Starting the panel seems to do nothing / no window appears
      Most likely it is ALREADY running - the installer starts it, and it lives
      in the notification area. Look behind the clock (click the ^ arrow next
      to the clock) and double-click the trackpad icon.

      In this version a second launch is no longer silent: it asks the running
      instance to show its window, so double-clicking the shortcut (or running
      the exe again, elevated or not) brings the settings window back. If an
      OLDER build is the one running, the launcher says so in a message box -
      end AmtPtpControlPanel.exe in Task Manager, then start the panel again.

      "Start hidden in system tray" (Startup group) makes the automatic login
      start tray-only by design; the window then comes back with a relaunch or
      a double-click on the tray icon.

      If there is really no window and no tray icon, run Diagnose.cmd and send
      MagicTrackpad-diagnose.txt - it reports the process, its windows (visible
      or not), the settings, the driver state and any startup error
      (%LOCALAPPDATA%\MagicTrackpad\panel-error.log).

The panel says "Failed to open device. Error: 2"
      First check the usual suspects:
        1. replug the USB-C cable (or remove + re-pair Bluetooth), then run
           Install.cmd again;
        2. reboot once - a stuck WUDF host or a stale device instance is common
           right after moving the trackpad between PCs;
        3. run Uninstall-All-Apple-Drivers.cmd (clean slate), replug, reboot,
           then Install.cmd; Install.cmd -Clean does 3 + install in one pass.

      Bluetooth trackpad on Windows 11 (build 22000+) with Secure Boot?
      Then it is the driver signature - see below. Just run Install.cmd again:
      when a trackpad is attached and the driver does not come up, the installer
      repairs the machine by itself (removes every old Apple / self-signed
      driver package and leftover device instance, installs the Microsoft-signed
      driver and restarts the trackpad devices). If the trackpad was paired over
      Bluetooth before, remove and re-pair it once afterwards.

      If it still fails, it is the driver signature or a stuck device:
        * the shipped package is signed by MICROSOFT and needs no test signing -
          check that no OLD self-signed package is still installed and winning:
              Uninstall-All-Apple-Drivers.cmd
              Install.cmd
          (a plain Install.cmd does this automatically)
        * test signing must be OFF on a normal machine. If it was turned on for
          an earlier self-signed driver, turn it back off and reboot:
              bcdedit /set testsigning off
        * did you build the driver yourself?  A self-signed build only loads with
          test signing on; the Microsoft-signed package in driver\ does not.

      The installer also prints the state of every connected trackpad device and
      whether test signing / Secure Boot are on. Diagnose.cmd collects all of it.

Legacy text follows.

The panel says "Failed to open device. Error: 2" (older notes)
      Error 2 = the driver's control device (\\.\AmtPtpControlDeviceUm) does not
      exist, which means the trackpad is not bound to this driver (yet). In
      order:

        1. replug the USB-C cable (or remove + re-pair the Bluetooth
           connection), then run Install.cmd again;
        2. reboot once - a stuck WUDF host or a stale device instance is the
           most common cause right after switching the trackpad between PCs;
        3. run Uninstall-All-Apple-Drivers.cmd (double-click) to remove every
           old Apple/trackpad driver package and leftover device instance, then
           run Install.cmd again. It also reports third-party tools that hijack
           the trackpad (Magic Utilities, Trackpad++) - uninstall those through
           Apps & features;
        4. Install.cmd -Clean does step 3 and the install in one go;
        5. still failing? The installer prints every connected trackpad device
           ID it can find. Send that list - if the hardware ID is not one of
           USB\VID_05AC&PID_0324, USB\VID_27A7&PID_2501/9601 or the Bluetooth
           HID form of 0324, the driver INF does not cover that model yet.

Battery shows "no reading"
      Normal over USB-C - the trackpad only reports the battery over
      Bluetooth. Pair it, then use the panel's Battery group.

The tray icon shows only a grey "?"
      Same reason: Bluetooth-only value. Over USB the panel says so instead
      of inventing a number.

Windows does not show the percentage as text next to the tray icon
      Windows 10 has no such option at all and Windows 11 hides tray labels
      by default. The number is therefore drawn inside the tray icon itself
      and appears in the tray menu ("Show battery percentage in tray -
      NN %"); the icon's Text/label carries the short value ("100%") for
      systems that do show tray labels.

Nothing happens on double-click / a second launch does not appear
      The panel is single-instance and elevated: the first process owns the
      tray icon. Use the tray menu -> "Open" (or double-click the icon).

--------------------------------------------------------------------------------
UNINSTALL
--------------------------------------------------------------------------------

       Uninstall.cmd

or, on the command line:

       powershell -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall

It removes the panel folder, the autostart entry, the imported driver package
and the two certificates again. (Log off/on afterwards to drop the tray icon.)
